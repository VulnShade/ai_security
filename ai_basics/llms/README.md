# LLMs 
- Use deep learning to understand and generate human-like text
- Ai system trained on massive amounts of text data
- Can process and respond to natural language inputs

## How LLMs Work

1. Tokenizing
    - Every word converted to numbers

2. Embedding
    - Words stored in association with other words
    - Stored as weights in a vector database

3. Transforming
    - Next words predicted

4. Generating
    - Generate entire sentence

## GPT (Generative Pre-trained Transformer)
- Based on neural network called a transformer
- Uses self-attention mechanism to process and generate text
- Forward only
- Great at generating text

### Pre-Training and Fine-tuning
- Pre-training
    - Initially trainined on large corpus of text 
- Fine-tuning
    - Trainined on specific dataset for specific purposes


## BERT (Bidirectional Encoder Representations from Transformers)
- Understands context of words by examining words before and after them
- Processes text bidirectionally
- Great at understanding context, not for text-generation
- Best for:
    - Text classification
    - Question answering
    - Search and info retrieval
